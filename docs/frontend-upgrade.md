# 手机竖屏前端升级 · 2026-10-28

## 最终设计

按用户选定的图 1（冰川装备橱窗）重做；以雪山照片、大幅真实雪板、双列身体数据和单行偏好切换为核心。均衡蓝色、灵活绿色、稳定红色；主题作用于文字、雪山氛围、问卷入口、滑杆、选中态、主按钮、弹层和结果页。

- 型号搜索、人群筛选、产品详情收进“更换雪板”底部弹层。
- 身高与体重支持输入及滑杆；雪鞋、站姿、滑行风格直接展示，不折叠；推荐按钮位于完整表单之后。
- 雪板入场 800ms、文案入场 700ms、页面退出 160ms/进入 600ms、底部弹层 500ms、主题和偏好滑块约 450–500ms。主要动画仅使用 opacity / transform。
- 系统减少动态效果时关闭 CSS 动效，页面转场直接执行；不支持 Web Animations 的旧内核直接切换。
- 推荐核心、46 款规格、站姿计算和小红书桥接保持原有实现。新增背景为本地 WebP，173 KiB，无远程运行依赖。
